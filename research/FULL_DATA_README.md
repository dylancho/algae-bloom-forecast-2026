# 2026 DATA·AI 분석 경진대회 — 댐·하천 유해남조류(녹조) 7일 예측

대상 지점 5개소의 수질·수문·기상 자료를 결합한 분석용 데이터 번들이다.
참가자는 오픈API를 직접 호출하지 않고 이 파일들만으로 학습·예측할 수 있다.

생성일 '26. 9. 12.

## 과제

지점별 **기준일(base_date)로부터 7일 후 유해남조류 세포수(cells/mL)** 를 예측한다.
회귀 단일 과제이며 배점 100%다.

### 예측 대상 매칭 규칙

조류경보제 채수는 매일이 아니라 평상시 주 1회, '경계' 이상 발령 시 주 2회 이상이며
강우·유량 증가 시 미채수가 발생한다. 따라서 아래 규칙으로 정답을 정의한다.

- 기준일은 **실측이 존재하는 날짜**로 한정
- 정답은 `base_date + 7일`에 **가장 가까운 측정일**의 값, 차이가 **±3일 이내**인 경우만 인정
- 해당 범위에 측정이 없거나 정답이 결측이면 그 조합은 **채점 대상에서 제외**
- `target_date`에는 예측 대상일이 아니라 **실제 정답 측정일**을 기재

이 규칙으로 전체 측정의 **93.7%** 가 채점 대상이 된다.
허용 오차별 매칭률은 ±0일 79.0%, ±1일 92.5%, ±2일 95.1%, **±3일 99.1%** 로,
±3일이 완결성과 시차 왜곡 사이의 균형점이다.

채점 대상 조합은 `eval_pairs.csv`에 모두 나열되어 있다.

## 데이터 분할

| 구분 | 기간 | 조합 수 |
|---|---|---:|
| 학습 (train) | ~ '24년 | 2,310 |
| 검증 (valid) | '25년 | 256 |
| 평가 (test) | '26년 **5~10월** | 124 |

'26년 중 5~10월 밖의 조합 64건은 `split=excluded`로 표시했으며 채점 대상이 아니다.
녹조는 수온이 오르는 5~10월에 집중되므로 평가 구간을 이 기간으로 한정했다.

## 제출 형식

CSV(UTF-8), 4개 컬럼. `sample_submission.csv`의 행 구성을 그대로 사용한다.

| 컬럼 | 설명 | 타입/단위 |
|---|---|---|
| `station_id` | 지점 식별자 | String |
| `base_date` | 예측 기준일(측정일) | Date, YYYY-MM-DD |
| `target_date` | 정답 측정일 | Date, YYYY-MM-DD |
| `pred_cells` | 예측 유해남조류 세포수 | Integer, cells/mL |

## 평가지표

- **순위 반영** — `log10(세포수+1)` 변환 RMSE·MAE, 원 단위 R²·NSE 병행
- **순위 미반영 참고** — 경계 기준 10,000 cells/mL 초과 여부 F1

## 참가 규정

- 예측값 하드코딩, 실측치 룩업테이블 포함 금지
- 기준일 이후 시점의 관측값을 입력으로 사용 금지
- 재현 실행 결과가 제출 파일과 유의하게 다를 경우 실격

## 재현

`collect_dataset.py`로 전 과정을 재현할 수 있다.

```
python collect_dataset.py stations
python collect_dataset.py algae  --from 2012 --to 2026
python collect_dataset.py dam    --from 2012-01-01 --to 2026-09-11
python collect_dataset.py asos   --from 20120101 --to 20260911
python collect_dataset.py damapi --from 2026-06-10 --to 2026-09-11
```

조류경보제·ASOS·다목적댐 운영정보는 공공데이터포털 인증키가 필요하며
`DATA_GO_KR_KEY` 환경변수로 전달한다. WAMIS는 인증키가 필요 없다.
